FEFO auto-select · multi-batch · manual override

FEFO auto-select behaviour: When you type (or accept) a Send Qty, the source batch(es) auto-fill using First-Expiry-First-Out order. If the qty spans multiple batches, extra lines are added automatically. You can override any auto-selection manually — change the batch dropdown or the qty per line. Clearing Send Qty resets all source lines.
