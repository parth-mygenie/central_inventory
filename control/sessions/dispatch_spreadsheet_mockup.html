Source Segment — spreadsheet adaptation:
  • Auto-selected to FEFO segment when row first loads (if only 1 segment, no action needed). Storekeeper just hits Tab to advance.
  • If multiple segments exist: compact dropdown showing BATCH-NAME · qty avail. Expiry warnings inline (14d left ⚠).
  • If source-options returns 403 (cross-store unauthorized): dropdown switches to bucket options — same 4 values, same compact shape.
  • No mode toggle buttons in the row — mode switches automatically based on API response. Keeps Source column narrow.
  • When a row is excluded, Source cell is cleared and not loaded (saves N API calls for excluded rows).

Source Segment compact adaptation (key design decision):
  • Auto-FEFO: When SourceSelector loads, auto-select the segment with earliest expiry that has enough stock. No action needed from storekeeper if they agree. Tab advances immediately.
  • Compact select: Instead of Segment/Bucket toggle buttons + separate select, a single <select> element. Mode is inferred from API response — no UI toggle in the row.
  • Deferred loading: Source options load on row focus (not on page load), avoiding 257 simultaneous API calls.
  • Excluded rows: Source not loaded at all — saves API calls for rows the storekeeper won't dispatch.
  • Bucket fallback: If source-options returns 403, dropdown auto-switches to bucket options (same 4 values). A small shield icon indicates bucket mode.
  • One caveat: SourceSelector is an async component with its own loading/error states. The compact version still needs to show a spinner inside the cell while fetching. This is the only cell that is asynchronous in the table.
